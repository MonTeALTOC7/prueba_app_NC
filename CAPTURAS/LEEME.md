# Evidencia visual

`antes/`: aplicación recibida, computadora. `despues/`: aplicación mejorada, computadora; `movil/`: vistas de 390 × 844 px. Las capturas son de navegador real con los datos incluidos en el paquete.

Las vistas de después muestran además algunos controles accionados durante QA (por ejemplo, unidad LT en Insumos y pendientes consultados en Inicio). No representan necesariamente el estado inicial de todos los filtros. `riego-exportado.png` es el archivo producido por la función de exportación de Riego.

Para comparar la estructura y la paleta, abrir el mismo módulo antes y después. Las capturas móviles corresponden a emulación de tamaño de pantalla, no a pruebas de hardware de un teléfono.
